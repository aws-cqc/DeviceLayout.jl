Experimental Solid Model API Reference

See Solid Models (Experimental) for how these fit together. The module exports nothing; import names from DeviceLayout.SolidModelsExperimental.

Layers and source stacks

DeviceLayout.SolidModelsExperimental.LayerRef — Type
LayerRef(layer::Symbol) <: DeviceLayout.Meta

Metadata for placing entities on a SourceLayer.

source
DeviceLayout.SolidModelsExperimental.Material — Type
Material

Material of a SourceLayer: METAL, DIELECTRIC, or NULL. Terminal selection uses the 2D METAL layers; the other materials are treated alike.

source
DeviceLayout.SolidModelsExperimental.SourceLayer — Type
SourceLayer(material::Material; kwargs...)

A layer in a SourceStack. Geometry entities are placed into this layer using a LayerRef pointing to it:

place!(cs, entity, LayerRef(:layer))

Layers with nonzero thickness or a source => destination level pair are automatically extruded during rendering (see below).

Keywords

  • level: level of the chiplet assembly at which the layer's 2D geometry is placed, or a pair of levels source => destination that the layer spans. Default is 1.
  • offset: z displacement from level; for a level pair, a pair of displacements, or one applied equally to both ends. Default is 0μm.
  • thickness: extrusion distance. Default is 0μm.
  • gds_meta: GDSMeta of the layer's artwork, used for rendering to a Cell. Set nothing to omit the layer from the artwork. Default is nothing.
  • solidmodel: If false, omit the layer from the solid model. Default is true.
source
DeviceLayout.SolidModelsExperimental.SourceStack — Type
SourceStack(layer_pairs...; levels)

A dictionary of layer names (Symbol)s to SourceLayers.

The levels dictionary maps levels of the chiplet assembly to z coordinates.

Lengths supplied via the layers and the levels mapping must be all unitful or all unitless (in micrometers).

source

Locators

DeviceLayout.SolidModelsExperimental.Locator — Type
Locator(p::Point)
Locator(x, y)

A point for marking 2D entities in a solid model for selection.

A Locator is place!d into a CoordinateSystem like any other geometry entity, using a LocatorMeta as metadata:

place!(cs, locator, locator_meta)

The type of LocatorMeta that is used determines the type of selection that is made. Current available options are Terminal, Ground, Tag, LumpedPort, or WavePort.

source
DeviceLayout.SolidModelsExperimental.LocatorMeta — Type
LocatorMeta <: DeviceLayout.Meta

Abstract supertype of all metadata used for placing Locators.

source
DeviceLayout.SolidModelsExperimental.Terminal — Type
Terminal(layer, name)

Locator metadata naming the terminal formed by the contiguous surface of 2D metal containing the locator. The resulting selection can be used in electrostatics simulations.

source
DeviceLayout.SolidModelsExperimental.Ground — Type
Ground(layer)

Locator metadata for marking a contiguous surface of 2D metal as ground. The resulting selection can be used in electrostatics simulations.

source
DeviceLayout.SolidModelsExperimental.Tag — Type
Tag(layer, name)

Locator metadata naming the surface containing the locator. The resulting selection can be used for any purpose, for example for computing surface integrals of field solutions over the specified surface.

source
DeviceLayout.SolidModelsExperimental.Port — Type
Port

Abstract supertype of locator metadata types used for selecting ports.

source
DeviceLayout.SolidModelsExperimental.WavePort — Type
WavePort(layer, name)

Locator metadata naming the wave port formed by the boundary patch intersecting the locator's (x, y) position. Create the patch by extruding a LineSegment on the simulation boundary, with the locator placed on the segment.

source
DeviceLayout.SolidModelsExperimental.LumpedPort — Type
LumpedPort(layer, name; kwargs...)

Locator metadata naming the lumped port surface containing the locator. The port direction is the DeviceLayout.WithDirection style of the selected port entity.

Keywords

  • index: Distinguishes ports sharing name; a port with index other than 1 is serialized as name_index. Default is 1. Useful for multi-element ports.
source

Operations

DeviceLayout.SolidModelsExperimental.Extrude — Type
Extrude(source; kwargs...)
Extrude(source, dz)
Extrude(destination, source; kwargs...)
Extrude(destination, source, dz)

Extrude a 1D or 2D layer along z, in place or into destination. By default, a SourceStack layer is extruded to its declared thickness or level span. Generated layers (i.e. layers not present in the source stack but generated by operations) need dz or to_level.

Keywords

  • to_level: Chiplet assembly level to extrude to. The source geometry must be planar.
  • offset: Displacement from to_level.
source
DeviceLayout.SolidModelsExperimental.Hollow — Type
Hollow(layer)

Replace a 3D layer by its boundary, removing its interior from the final model even where other volumes overlap it. Boundary faces that bound no remaining volume are removed too.

source
DeviceLayout.SolidModelsExperimental.Cut — Type
Cut(destination, object, tools; kwargs...)

Subtract tools from object. tools can be a single layer symbol or a collection of them. destination must be new or one of the inputs, and object must not be one of the tools.

Keywords

  • remove_object: If true, consume object. Default is false.
  • remove_tool: If true, consume every tool. Required if destination is one of several tools. Default is false.
source
DeviceLayout.SolidModelsExperimental.Fuse — Type
Fuse(source)
Fuse(destination, sources; kwargs...)

Union sources into destination. sources can be a single layer symbol or a collection of them. destination must be new or one of the sources. Fuse(source) merges overlapping geometry of source in place.

Keywords

  • remove_sources: If true, consume every source. Required if destination is one of several sources. Default is false.
source
DeviceLayout.SolidModelsExperimental.Intersect — Type
Intersect(destination, object, tool; kwargs...)

Compute the intersection of object and tool and assign to destination, which must be new or one of the inputs. The result has the lower of the input dimensions.

Keywords

  • remove_object: If true, consume object. Default is false.
  • remove_tool: If true, consume tool. Default is false.
source
DeviceLayout.SolidModelsExperimental.GetInterface — Type
GetInterface(destination, object, tool)

Compute the interface between object and tool and assign to destination, which must be new. The interface of inputs of equal dimension is one dimension lower; otherwise it has the lower input dimension.

source
DeviceLayout.SolidModelsExperimental.RestrictTo — Type
RestrictTo(volume)

Restrict the model to the 3D layer volume.

source
DeviceLayout.SolidModelsExperimental.GetBoundary — Type
GetBoundary(source; kwargs...)
GetBoundary(destination, source; kwargs...)

Extract the boundary of source, in place or into destination, which must be new or source.

Keywords

  • combined: If true, return the boundary of the combined shape rather than of each entity. Default is true.
  • oriented: If true, orient the boundary entities. Default is true.
  • recursive: If true, return boundaries recursively down to points. Default is false.
  • direction: "x", "y", or "z" (case-insensitive) to return only boundaries perpendicular to that axis, or "all". Default is "all".
  • position: "min" or "max" to return only boundaries at that end of direction, or "all". Default is "all".
source
DeviceLayout.SolidModelsExperimental.exterior_boundaries — Function
exterior_boundaries(bounding_volume::Symbol) -> Vector{GetBoundary}

Return operations extracting the six axis-aligned exterior faces of bounding_volume into layers :EXTBND_XMIN, :EXTBND_XMAX, :EXTBND_YMIN, :EXTBND_YMAX, :EXTBND_ZMIN, and :EXTBND_ZMAX.

source
DeviceLayout.SolidModelsExperimental.Translate — Type
Translate(source, dx, dy, dz)
Translate(destination, source, dx, dy, dz)

Translate source by (dx, dy, dz), in place or into destination.

source
DeviceLayout.SolidModelsExperimental.Remove — Type
Remove(source; kwargs...)

Remove source from the model, if present.

Keywords

  • remove_entities: If false, remove only the layer's physical groups, keeping its entities. Default is true.

Geometry that passes through a Cut, Fuse, or Intersect unchanged belongs to both its input and its result, so removing the input with Remove also removes it from the result. Consume inputs with the operations' removal flags instead.

source
DeviceLayout.SolidModelsExperimental.Revolve — Type
Revolve(source, origin, axis, angle)
Revolve(destination, source, origin, axis, angle)

Revolve source by angle around the axis through origin along axis, in place or into destination. origin is a 3-tuple of coordinates, axis a unitless 3-tuple, and a unitless angle is in radians. The result is one dimension higher than source.

source
DeviceLayout.SolidModelsExperimental.SetPeriodic — Type
SetPeriodic(first, second)

Make the distinct, parallel, axis-aligned 2D layers first and second periodic.

source

Rendering

DeviceLayout.SolidModelsExperimental.SolidModelTarget — Type
SolidModelTarget(stack::SourceStack, operations=LayerOp[])

Target for rendering a Schematic to a solid model with render!, using the source layers of stack and applying the layer operations in order.

source
DeviceLayout.render! — Method
render!(sm::SolidModel, sch::Schematic, target::SolidModelTarget; kwargs...) -> Dict{String, Any}

Render sch to sm, using rendering settings from target, and return the solid model's metadata (physical groups, layers, and selections).

Keywords

  • select_terminals: If false, skip the identification of contiguous 2D metallic islands marked by Terminal or Ground locators. If true, the model must have 2D layers with METAL as their material. Default is true.
  • select_tagged_surfaces: If false, skip selecting surfaces marked by Tag locators. Default is true.
  • select_ports: If false, skip selecting surfaces marked by LumpedPort or WavePort locators. Default is true.
  • strict: :error, :warn, or :no. With :error, throw an error if any errors were logged while building component geometries, rendering geometries to sm, or selecting locators. With :warn, also throw if any warnings were logged. With :no, any component which was not successfully built has an empty geometry. Default is :error.

Other keyword arguments are passed on to SolidModels.render!.

source
DeviceLayout.render! — Method
render!(cell::Cell, cs, stack::SourceStack; kwargs...)

Render cs to cell, mapping each LayerRef to the gds_meta of its layer in stack. Layers with gds_meta=nothing are not rendered.

Keywords

  • levels: Assembly levels being rendered. If it has more than one entry, each layer's GDS layer and datatype are offset by (level - 1) * level_increment, where level is the first level of the layer (or 1 if that is lower). Default is [1].
  • level_increment: GDSMeta offset per level. Default is GDSMeta(0, 0).

Other keyword arguments are passed on to render!(::Cell, ::GeometryStructure).
